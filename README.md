# purchases-ios-spm

This repository is an automated, **tags-only mirror** of
[RevenueCat/purchases-ios](https://github.com/RevenueCat/purchases-ios), published to
**make Swift Package Manager integration faster**.



## Usage

Point SPM at this repository and pin a released version:

```swift
.package(url: "https://github.com/RevenueCat/purchases-ios-spm.git", from: "<version>")
```

Every release tag here is byte-identical to the same tag in `purchases-ios`.

## Contributing
